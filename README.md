🛠️ Acerca del Proyecto

Este proyecto fue desarrollado para la materia Aplicaciones desarrollo Mobile por el tema designado de Vapers. 

Público Objetivo: Adolescentes de 13 a 18 años.

Objetivo Principal: Concientizar sobre los riesgos del uso del vapeo, la adicción a la nicotina y sustancias dañinas.


🚀 Tecnologías Utilizadas

Lenguaje: Kotlin

UI Framework: Jetpack Compose

Entorno de Desarrollo: Android Studio

Build System: Gradle (Kotlin DSL)

🔧 Requisitos Previos

Antes de importar el proyecto, se necesita contar con los siguientes elementos instalados:

Android Studio.

JDK: Java Development Kit 17 o superior (incluido en Android Studio).

SDK de Android: Android API Level 24 (Android 7.0) o superior.

Plugin de Kotlin: Soportado de forma nativa con soporte completo para Jetpack Compose.

Emulador de Android / Dispositivo Físico: Con la depuración USB activada.

⚙️ Instalación y Configuración

Seguir estos pasos para descomprimir y ejecutar la aplicación desde el archivo ZIP:

Descargar y descomprimir el archivo:

Descarga el archivo comprimido trampaVapeo.zip.

Descomprime el archivo .zip en una carpeta elegida en tu computadora.

Abrir en Android Studio:

Inicia Android Studio.

En la pantalla de bienvenida o en el menú superior, selecciona Open (Abrir).

Navega hasta la carpeta donde descomprimiste el proyecto y selecciónala.

Espera a que Android Studio importe el proyecto y Gradle realice la sincronización inicial (Gradle Sync).

Ejecutar la aplicación:

Conecta tu dispositivo móvil Android mediante cable USB (con depuración USB activa) o inicia un emulador desde el Device Manager.

Presiona el botón Run (Shift + F10 o el icono ▶️) en la barra superior para compilar e instalar la app.
